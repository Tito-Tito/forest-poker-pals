# 동물 테마 포커 카드 퍼즐 — 의도 문서

- 처음 확정: 2026-11-26
- 규칙 변경: 2026-11-27 (원작 방식 규칙으로 변경)
- 난이도 조정: 2026-11-27 (목표 점수가 너무 높아 낮춤)

## 목표 (Why)
paganuko.com의 카드 퍼즐(Willie Wheeler)과 같은 장르·메커니즘의 **오리지널 게임**을 만든다.
게임 규칙 구조는 원작 방식을 따르되, 이름·캐릭터·아트·화면 구성은 새로 만든다.

## 형태
- 브라우저에서 바로 열리는 단일 HTML 파일(`index.html`). 설치·빌드 불필요.
- GitHub Pages로 배포: https://tito-tito.github.io/forest-poker-pals/ (`main` 브랜치 루트)
- 진행 상황은 브라우저 localStorage에 자동 저장, 다시 열면 이어하기.
- 주 사용 기기: 아이폰 Safari(홈 화면에 추가)와 PC 브라우저. 375px 폭에서 가로 스크롤 없이 한 화면에 들어가야 한다.

## 핵심 규칙 (원작 방식)
- 보드: 날개 4개(서·동·북·남). 날개마다 카드 4장 + 가운데 **고정 카드 1장**(움직일 수 없음).
- 날개의 **5장**(카드 4장 + 고정 카드)으로 포커 족보를 판단한다.
- **이동 1**을 쓰는 행동:
  - 뽑기: 덱에서 카드 1장을 받는다.
  - 맞바꾸기: 서로 다른 날개의 카드 두 장, 또는 보관함 카드와 날개 카드를 맞바꾼다.
- **무료** 행동(뽑은 카드 처리):
  - 날개 칸에 놓기 → 원래 카드는 보관함으로(보관함이 차 있으면 버려짐)
  - 보관함에 넣기(2칸)
  - 버리기
- 총점 = (족보가 있는 날개 점수 × 날개 보너스)의 합 × 족보가 있는 날개 수
- 제한된 이동 안에 목표 점수를 넘기면 레벨 클리어. 일찍 끝내면 남은 이동만큼 코인 보너스.
- 보조 기능: 다음 카드 2장 미리보기, 힌트(처음 5개, 클리어마다 +1, 코인으로 구매).

## 레벨·해금
- 레벨이 오를수록 목표 점수와 이동 횟수가 늘어난다. 튜토리얼 포함.
- 처음엔 서·동 날개만 열림. 북쪽은 레벨 5(점수 ×4), 남쪽은 레벨 10(점수 ×9)에 열린다. (원작과 같은 수치)
- 레벨별 목표 점수는 `tools/simulate.py`의 자동 플레이 결과로 정한다. 기준: 모든 수를 계산하는 AI가 약 85~90% 깨는 점수. 사람이 "조금 고민하면 대부분 깬다"고 느껴야 한다.
- 레벨 15 이후 목표는 한 레벨에 100점씩 오른다.

## 테마 (동물)
- 배경: 동물들이 사는 숲 속 공터.
- 날개 주인: 서=🦊 여우, 동=🐰 토끼, 북=🦉 부엉이(해금), 남=🐻 곰(해금).
- 날개에서 족보가 완성되면 해당 동물이 기뻐하는 반응.

## 완료 기준 (Success)
- 브라우저에서 열면 튜토리얼부터 여러 레벨까지 끝까지 플레이 가능.
- 날개 잠금 해제가 정해진 레벨에서 정상 작동.
- 아이폰 Safari에서 정상 플레이 가능.
